# Instruções para Agentes de IA

Este projeto é um monorepo reconstruído do zero.

Leia primeiro:

- CLAUDE.md
- docs/APP_CONTEXT.md

Não implemente funcionalidades sem entender o contexto do produto.

Prioridades:
- calma;
- clareza;
- interface limpa;
- segurança;
- escopo pequeno;
- validação;
- documentação.

Comandos obrigatórios antes de considerar uma tarefa pronta:

- pnpm lint
- pnpm typecheck
- pnpm build
